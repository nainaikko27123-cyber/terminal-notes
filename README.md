# Terminal Notes 💚

A macOS notes app styled like a retro terminal, with a desktop widget to match.

## Features
- **Terminal look:** green-on-black text, a blinking prompt, a status bar and tabs
- **Commands:** type things like `:opacity` to change the app on the fly
- **Autosave:** notes are saved as Markdown files in a local folder
- **Desktop widget:** see your notes right on your desktop (WidgetKit)
- **Now playing:** shows the current Spotify track in the top bar
- **Small touches:** Pac-Man loading animation and a status LED

## Built with
Swift · SwiftUI · WidgetKit · App Groups · a Swift package (`NotesKit`) for the note model and storage

## Run it
Open `NotesApp.xcodeproj` in Xcode, choose your own signing team, and press **Run**.
